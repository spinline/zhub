Ziggurat adds Green Power frame reception at the stack boundary. This does not
add Green Power device support to zhub. The upstream EUI64 conversion helpers
replace the old Spinel helpers with equivalent byte ordering on the host;
the firmware-side EUI64 fix applies to Ziggurat-in-OT. No radio firmware is
flashed by this update.

The vendored Spinel client is updated to the same revision. Its zhub-specific
250 ms transmit timeout remains in place, with the original 2 s timeout for
delayed CSL transmissions and other commands.

Relevant rs-matter changes include commissioning PASE expiration, subscription
keep-alive reports, persistence error recovery, fabric index allocation and
CASE session negotiation fixes. Its interaction model state and async utility
APIs changed; the bridge is adapted to the new interfaces. The existing
Keenetic integration still publishes mDNS advertisements through Avahi service
files, rather than the upstream D-Bus backend.
